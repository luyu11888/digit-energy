# 数字能量馆 · 手机号磁场 × 本命幸运数字

一个**纯静态、开箱即用**的数字能量学分析网页：

- 输入**手机号** → 按数字能量学“八星磁场”逐段拆解：天医 / 生气 / 延年 / 伏位 / 绝命 / 五鬼 / 六煞 / 祸害，给出吉凶统计、总评、白话解说与尾段重点；
- 再报上**出生生辰** → 由开源历法库 `lunar.js` 推四柱五行与喜用神，把“数字五行（河图数）”对上“命中宜补之气”，输出**本命幸运数字、号码契合度与专属尾号参考**；
- 页面内置**留灯结缘**获客位：页底写下“想解决的方向”，一点即弹店主微信二维码、并自动复制成加好友备注，客户扫码加微信私聊；分析本身**每日免费一次**，用罄后可随缘添灯（与「易学铺子」同款模式）。

双击 `index.html` 即可离线使用；也可整体推送到 GitHub Pages / Cloudflare Pages 等任意静态托管。移动端自适应，与「深情猫玄学馆」八字、六爻等网页同一套古风视觉。

> 号码是一串随身携带的数字，磁场在其中静静流转——看得懂它，才不会被它牵着走。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 号码磁场分析 | 相邻两两成组拆解整号（0 与 5 作特殊位处理），位置权重自左向右递增，尾段高亮 |
| 磁场总评 | 吉星/凶星/中性/特殊计数 + 吉气占比圆环 + 评级白话 |
| 逐段拆解表 | 每组数组 → 所属星、能量档（一~四等/延续）、组内两字各自五行 |
| 白话解说 | 主调星、连续凶星段、尾段收尾、0/5 提示等规则化生成 |
| 八星分布条 | 八星命中组数一望而知；页面底部另有「八星磁场速查表」 |
| 八字契合 | 填出生时间后：四柱简排、八字五行能量、号码数字五行含量、契合度百分比 |
| 本命幸运数字 | 按喜用/宜补五行给出河图幸运数字大卡（例：喜水 → 1、6） |
| 专属尾号参考 | 由“吉星 × 本命数字”两两组合生成安全尾号候选（中间跨界组不含凶星/0-5） |
| 每日一测 · 随喜 | 分析每日免费 1 次，用罄后弹店主收款码浮层，随喜后当日放行（见下文） |

```
digit-energy/

├── data.js           知识库：八星磁场对照表、数字五行、店铺与线索配置 SHOP

├── app.js            页面渲染 + 线索收集 + 店主后台 #admin
```

加载顺序（`index.html` 内已按序引入）：`lunar.js → data.js → astro.js → core.js → app.js`。

## 玩法规则与数据来源说明

- **拆法**：取手机号全部 11 位，自左向右每次取相邻两位组成数组（共 10 组）。越靠右侧（越接近尾数）位置权重越高，`收尾`两组影响最大——这是数字能量学“看号先看尾”的通行做法。号段侧数组权重最低，仅作底色。
- **八星对照**：吉星「天医、生气、延年」、中性「伏位」、凶星「绝命、五鬼、六煞、祸害」，每星 8 组数字、按能量强弱分四档（伏位为延续档）。对照关系属数字能量学公开资料的通行整理，细节在不同流派书籍/工具间存在差异，本页采用最常见版本。
- **0 与 5**：按主流理论作“特殊位”——5 主显化放大、0 主空藏收敛，不参与吉凶判星，只作提示。
- **数字五行**：采用“河图数”——1、6 水；2、7 火；3、8 木；4、9 金；5、0 土。
- **八字喜用**：历法干支一律由 `lunar.js`（6tail 开源库，MIT）精确计算；旺衰用“得令 / 通根 / 透干”简化模型，喜忌按扶抑法粗取。时辰不详时页面支持按“午时”粗参，仅影响时柱一柱。
- **评分与评级**：为便于展示而做的**趣味模型**（吉凶按位置与能量档加权、中性微计），不是学术标准。请勿把数字解读当成决策依据。

## 留灯结缘：引导客户加店主微信

页面底部「留灯结缘」**不再直接收集手机号**，改为更轻的私域获客闭环：

1. 客户在「想解决的方向」写一句诉求（如：想看现用号磁场、想换开运尾号、财运/事业/姻缘哪方面不顺）；
2. 点「留灯给馆主」→ 页面把这句话**自动复制为“加好友备注”**，并弹出**店主微信二维码**；
3. 客户扫码加店主微信、粘贴备注发送，馆主照着备注直接与客户详聊（是否免费看、如何引导随缘，由店主线下把握）。

本机记录与转发（可选）：

- 每次留灯仍在**本机浏览器** `localStorage` 留档；店主在网址后加 `#admin` 可查看 / 导出 CSV / 清空（只能看到本机提交过的那部分）。
- 如需跨设备收到留灯内容，把 `data.js → SHOP.collectEndpoint` 填成 Formspree / Getform / Web3Forms 的 endpoint（免费档均有邮箱通知），留灯会以 `{ wish, source }` 的 JSON POST 转发，**不含**手机号等个人联系方式。

> 店主微信：页面弹层展示根目录 `wechat-qrcode.png`（微信名片码）与 `wechat-pay.png`（微信收款码），并同步 `data.js → SHOP.wxId`。更换店主微信时三处一起换。

## 每日一测 · 随缘添灯（与易学铺子同款）

- 「开始分析」每日**免费 1 次**；输入卡标题右侧有“今日数缘”状态提示。
- 用罄后再点开始分析 → 弹「随喜添灯」浮层（店主收款码 + 加微信码）→ 客户随喜后**当日放行**，次日 0 点复满。
- 额度记在本机 `localStorage`（键 `NE_quota_v1`），**刷新 / 清缓存可重置**——与「深情猫的易学铺子」完全相同的“诚信问心”式轻门禁，页面文案亦如实声明“无法自动核验款项，全靠君一问心”，不作防刷承诺。

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库（如 `digit-energy`），把本目录文件全部推上去：
   ```bash
   git init
   git add .
   git commit -m "数字能量馆：手机号磁场 × 本命幸运数字"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/digit-energy.git
   git push -u origin main
   ```
2. 仓库 **Settings → Pages → Build and deployment → Source: Deploy from a branch → main / (root)**，保存。
3. 稍候即可访问 `https://<你的用户名>.github.io/digit-energy/`。

> 只部署本馆而不部署站群时，把 `data.js → SHOP.otherHalls` 保持空数组即可（默认已是空）；若与「子平八字」「周易起卦」等馆放在同一仓库做站群，再把各馆链接填进去。

## 改成自己的铺子

所有店铺文案、微信、链接都在 `data.js` 顶部的 `SHOP` 对象里一处改完全页生效：

| 字段 | 含义 |
| --- | --- |
| `name` | 馆名（导航 / 底部署名） |
| `hall` / `plaqueTop` / `motto` | 主匾标题、上方题字、座右铭 |
| `wechat` | 填上则在结果区“结缘”展示微信号，留空隐藏 |
| `wxId` | 店主微信号（弹层文字兜底），与二维码图配套 |
| `otherHalls` / `home` | 站群导航（见上） |
| `collectEndpoint` | 留灯内容外发地址（见上，可选） |
